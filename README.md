# Woo als een pro

Kennisbank en tools voor Woo-verzoeken. Doelgroep: LLM-agents en mensen.
Documenten zijn kort. Zij verwijzen naar wetstekst en jurisprudentie.

Deze repo bevat kennis, geen zaakgegevens. Een zaak beheert u in een eigen systeem (bijv. ODAS).
Agents: lees eerst [`AGENTS.md`](AGENTS.md).

## Structuur

| Map | Inhoud |
|---|---|
| [`docs/`](docs/) | Kennisbank: één onderwerp per document |
| [`templates/`](templates/) | Briefsjablonen met schrijfregels |
| [`wetten/`](wetten/) | Geldende wetstekst, één bestand per artikel |
| [`uitspraken/`](uitspraken/) | Jurisprudentie, één bestand per ECLI |
| [`bronnen/`](bronnen/) | Handreikingen, instructies en achtergrond, omgezet naar markdown |
| [`tools/`](tools/) | Software: brieven bouwen, wetten en bronnen ophalen (Engels) |
